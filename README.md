# CineVerse

**CineVerse** is a iOS movie discovery app built with SwiftUI, and Clean Architecture. The app consumes movie data from the **TMDB** API and provides a modern streaming-style experience with categorized movie lists, horizontal and vertical scrolling, search, movie details, cast, similar movies.

**Pet Project Goal** 🎯

The project is designed to explore iOS architecture and best practices, including protocol-oriented programming, generics, dependency injection, async/await, image caching, pagination, offline support, and unit testing.
